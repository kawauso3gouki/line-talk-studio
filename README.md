# Talk Studio

`index.html` をブラウザーで開くと、そのまま使えます。インターネット接続・インストールは不要です。

1. 「相手から」「自分から」を選び、文章と送信時刻を入力します。
2. 「メッセージを追加」を押します。画像は「写真・画像を貼る」で選んでから追加します。透明PNGは「スタンプとして貼る」に対応します。
3. 相手の名前・アイコン・背景色・背景画像・文字サイズ・ステータスバーなどを調整できます。
4. 「保存する範囲」で「スマホ1画面」または「全トーク（縦長画像）」を選び、「PNGを保存」を押します。1画面の表示位置はプレビュー下のスライダーで調整できます。

右の一覧でメッセージの編集、順序変更、削除ができます。プレビュー右上の矢印で元に戻せます。

添付されたAndroid版LINEの画面を参考に、青いヘッダー、淡い緑の吹き出し、返信の引用、下部の提案ボタンとAndroidのナビゲーションを再現しています。1対1のトーク用で、吹き出し上の名前や既読人数は表示しません。名前は上部のトーク名だけに表示し、既読は「既読」と表示します。「トーク画面の設定」の「添付画像の見た目に合わせる」で表示設定を揃えられます。トーク内容は消えません。

標準サイズ360 × 800、画質3倍、保存範囲「スマホ1画面」で、添付画像と同じ1080 × 2400pxになります。「相手の名前」で画面上部の名前を変更できます。「返信の引用」を開くと引用元の名前・文章を設定できます。従来のiPhone風スタイルも選べます。以前のグループ形式の編集データも、トーク内容を引き継いで1対1の表示で読み込めます。

編集中の内容はブラウザーに自動保存されます。画像が多く保存容量を超える場合は、一覧の下に表示されます。「編集データを保存」で画像を含んだJSONファイルに保存でき、「読み込む」で続きを編集できます。

画像は1枚20MBまで、トークは400件までです。大きすぎるPNGは画質を下げるか、トークを分けてください。

LINE風の画面を作る非公式ツールです。実際のLINEへのメッセージ送信は行いません。入力内容と画像はブラウザー内で処理します。
